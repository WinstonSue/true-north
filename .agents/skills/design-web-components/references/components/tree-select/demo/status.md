# Status

## Description (en-US)

Add status to TreeSelect with `status`, which could be `error` or `warning`.

## Source

```vue
<template>
  <sue-space direction="vertical" style="width: 100%">
    <sue-tree-select status="error" style="width: 100%" placeholder="Error" />
    <sue-tree-select status="warning" style="width: 100%" multiple placeholder="Warning multiple" />
  </sue-space>
</template>
```
