# Status

## Description (en-US)

Add status to DatePicker with `status`, which could be `error` or `warning`.

## Source

```vue
<template>
  <sue-space vertical style="width: 100%;">
    <sue-date-picker status="error" style="width: 100%;" />
    <sue-date-picker status="warning" style="width: 100%;" />
    <sue-range-picker status="error" style="width: 100%;" />
    <sue-range-picker status="warning" style="width: 100%;" />
  </sue-space>
</template>
```
