# Size

## Description (en-US)

A small `Spin` is used for loading text, medium sized `Spin` for loading a card-level block, and large `Spin` used for loading a **page**.

## Source

```vue
<template>
  <sue-flex align="center" gap="middle">
    <sue-spin size="small" />
    <sue-spin />
    <sue-spin size="large" />
  </sue-flex>
</template>
```
