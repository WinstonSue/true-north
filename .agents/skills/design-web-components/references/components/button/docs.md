## When To Use

- Use Button for user-triggered actions. Use `primary` for the main action in a section. See `demo/basic.md`.
- Use `color` and `variant` for explicit visual intent; `type` is shorthand for common presets. See `demo/color-variant.md`.
- Use `danger`, `disabled`, `loading`, or ButtonLoading for risky, unavailable, or async actions. See `demo/danger.md`, `demo/disabled.md`, `demo/loading.md`, and `demo/button-loading.md`.
- Use ButtonGroup.Confirm for cancel/confirm flows with async confirm loading. See `demo/confirm.md`.
- Use icon buttons or icon placement when the action benefits from a visual cue. See `demo/icon.md` and `demo/icon-placement.md`.

## API

### Button

#### Props

Common props ref：[Common props](../../docs/vue/common-props.md)

Different button styles generated by setting Button properties. The recommended order is: `type` -> `shape` -> `size` -> `loading` -> `disabled`.

| Property | Description | Type | Default | Version |
| --- | --- | --- | --- | --- |
| autoInsertSpace | We add a space between two Chinese characters by default. Set `autoInsertSpace` to `false` to disable. | boolean | `true` | - |
| block | Option to fit button width to its parent width | boolean | false | - |
| color | Set button color | `default` \| `primary` \| `danger` \| [PresetColors](#presetcolors) | - | - |
| danger | Syntactic sugar. Set the danger status of button. Will follow `color` if provided | boolean | false | - |
| disabled | Disabled state of button | boolean | false | - |
| ghost | Make background transparent and invert text and border colors | boolean | false | - |
| href | Redirect url of link button | string | - | - |
| htmlType | Set the original html `type` of `button`, see: [HTML Standard](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/button#type) | `submit` \| `reset` \| `button` | `button` | - |
| iconPlacement | Set the icon position of button | `start` \| `end` | `start` | - |
| loading | Set the loading status of button | boolean \| &#123; delay: number, icon: VueNode &#125; | false | - |
| shape | Can be used to set button shape | `default` \| `circle` \| `round` | `default` | - |
| size | Set the size of button | `large` \| `medium` \| `small` | `medium` | - |
| target | Same as target attribute of a, works when href is specified | string | - | - |
| type | Syntactic sugar. Set button type. Will follow `variant` & `color` if provided | `primary` \| `dashed` \| `link` \| `text` \| `default` | `default` | - |
| variant | Set button variant | `outlined` \| `dashed` \| `solid` \| `filled` \| `text` \| `link` | - | - |

### ButtonLoading

A button that manages asynchronous click loading state automatically. It supports all Button props except `loading`, which is controlled internally from the `onClick` return value.

#### Props

| Property | Description | Type | Default | Version |
| --- | --- | --- | --- | --- |
| onClick | Callback executed when the button is clicked. When it returns a Promise, loading is shown until it settles. | `(event: MouseEvent) => unknown` | - | - |

#### Slots

| Slot | Description | Type | Version |
| --- | --- | ---- | --- |
| default | Button content | - | - |
| icon | Set the icon component of button | - | - |
| loadingIcon | Set the loading icon component of button | - | - |

### ButtonGroup.Confirm

A cancel/confirm button group. The confirm button manages asynchronous loading state inside the group, and the cancel button is disabled while confirm is loading.

#### Props

| Property | Description | Type | Default | Version |
| --- | --- | --- | --- | --- |
| onConfirm | Callback executed when the confirm button is clicked. When it returns a Promise, the confirm button enters loading state. | `() => unknown` | - | - |
| onCancel | Callback executed when the cancel button is clicked | `() => void` | - | - |
| confirmText | Confirm button text | string | `确定` | - |
| cancelText | Cancel button text | string | `取消` | - |
| size | Size for both buttons. `default` means the Button default size is not overridden. | `default` \| `small` \| `medium` \| `large` | `default` | - |
| confirmProps | Props passed to the confirm Button. `loading` and `onClick` are not supported. | `Omit<ButtonProps, 'loading' \| 'onClick'>` | - | - |
| cancelProps | Props passed to the cancel Button. `onClick` is overridden by `onCancel`. | ButtonProps | - | - |

## FAQ

### How to choose type and color & variant?
`type` is syntactic sugar for common color and variant combinations. When `color` or `variant` is provided, those explicit props take priority. See `demo/basic.md` and `demo/color-variant.md`.


### How to close the click wave effect?
Disable wave globally through ConfigProvider `wave.disabled`. See `../config-provider/demo/wave.md`.
