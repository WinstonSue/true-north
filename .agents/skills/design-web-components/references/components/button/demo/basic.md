# Syntactic sugar

## Description (en-US)

Through the `type` syntactic sugar, use the preset button styles: `primary` buttons, `default` buttons, `dashed` buttons, `text` buttons, and `link` buttons.

## Source

```vue
<template>
  <sue-flex gap="small" wrap>
    <sue-button type="primary">
      Primary Button
    </sue-button>
    <sue-button>Default Button</sue-button>
    <sue-button type="dashed">
      Dashed Button
    </sue-button>
    <sue-button type="text">
      Text Button
    </sue-button>
    <sue-button type="link">
      Link Button
    </sue-button>
  </sue-flex>
</template>
```
