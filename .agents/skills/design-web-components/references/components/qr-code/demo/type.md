# Custom Render Type

## Description (en-US)

Customize the rendering results by `type`, provide options `canvas` and `svg`.

## Source

```vue
<template>
  <sue-space>
    <sue-qrcode type="canvas" value="https://www.@sue/design-web-vue.com" />
    <sue-qrcode type="svg" value="https://www.@sue/design-web-vue.com" />
  </sue-space>
</template>
```
