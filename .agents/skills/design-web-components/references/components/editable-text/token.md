# editable-text Token

Use these variables through `theme.components.EditableText`. This document lists definitions only and does not include values.

```ts
const customTheme = {
  components: {
    EditableText: {
      titleMarginTop: '1.2em',
      titleMarginBottom: '0.5em',
    },
  },
}
```

| Token | Type | Description |
| --- | --- | --- |
| titleMarginTop | number \| string | Margin top of heading-style EditableText |
| titleMarginBottom | number \| string | Margin bottom of heading-style EditableText |
