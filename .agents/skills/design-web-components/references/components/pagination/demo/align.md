# Align

## Description (en-US)

Set pagination alignment with `align`.

## Source

```vue
<template>
  <sue-space direction="vertical" size="medium" style="width: 100%">
    <sue-pagination align="start" :default-current="1" :total="50" />
    <sue-pagination align="center" :default-current="1" :total="50" />
    <sue-pagination align="end" :default-current="1" :total="50" />
  </sue-space>
</template>
```
