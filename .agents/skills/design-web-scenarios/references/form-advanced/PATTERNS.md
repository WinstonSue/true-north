# 高级表单实现协议

## 分区结构

- 一个顶层 `Form` 负责完整 payload。
- 每个业务分区一个 `Card`，标题必须是业务语义。
- 使用 `Row` / `Col` 控制响应式字段，不用固定像素拼布局。

## 可编辑表格

- 行数据属于 `formModel` 的明细数组。
- 使用稳定 `rowKey`，不要用数组索引。
- 单元格编辑用 `FormItem` 包裹控件，保证校验可定位。
- 新增、删除、保存行都要更新同一份明细数组。

## 错误摘要

- 提交失败时保存 `errorFields`。
- 摘要显示错误数量和首条错误。
- 点击错误项滚动到对应字段。
- 底部栏需要预留内容区 padding，避免遮挡最后一行字段。
