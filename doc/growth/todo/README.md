# 待办管理模块

## 1. 模块概述

待办事项是最基础的执行单元,提供日常任务的快速创建、管理和追踪。

**核心价值**:
- 日常任务快速记录
- 四象限优先级管理
- 完整的数据统计分析

## 2. 功能详解

### 2.1 待办视图

#### 2.1.1 今日待办 (todo-today)
- **今日计划**: 今日计划的待办事项
- **过期提醒**: 已过期的待办高亮显示
- **今日完成**: 今日已完成/已放弃的待办
- **快速创建**: 快速创建今日待办

#### 2.1.2 本周待办 (todo-week)
- **周视图**: 本周所有待办事项
- **分组展示**: 按日期分组
- **周统计**: 周度完成统计

#### 2.1.3 待办日历 (todo-calendar)
- **月度日历**: 月度日历视图
- **数量统计**: 每日待办数量统计
- **日期搜索**: 日期范围搜索
- **单元格列表**: 日历单元格显示待办列表

#### 2.1.4 全部待办 (todo-all)
- **表格视图**: 表格形式展示所有待办
- **高级筛选**: 多维度筛选功能
- **批量操作**: 批量修改、删除
- **多维排序**: 支持多种排序方式

#### 2.1.5 待办统计 (todo-dashboard)
- **完成趋势**: 任务完成趋势图表
- **优先级分布**: 优先级分布统计
- **效率分析**: 效率分析图表
- **数据看板**: 数据可视化看板

### 2.2 待办属性

#### 2.2.1 基础属性
- **待办名称** (name): 必填
- **描述** (description): 可选
- **状态** (status):
  - 待办 (Todo)
  - 进行中 (InProgress)
  - 已完成 (Done)
  - 已放弃 (Abandoned)

#### 2.2.2 关联属性
- **关联任务** (taskId): 可选
- **关联目标** (goalId): 可选

#### 2.2.3 时间属性
- **计划时间** (plannedAt): 计划执行日期
- **截止时间** (dueAt): 可选
- **完成时间** (doneAt): 系统记录
- **放弃时间** (abandonedAt): 系统记录

#### 2.2.4 优先级属性

**重要性** (importance): 1-5级
- 5 - 不容或缺
- 4 - 举足轻重
- 3 - 重要
- 2 - 略有裨益
- 1 - 聊胜于无

**紧急程度** (urgency): 5级
- 十万火急 (ASAP)
- 刻不容缓 (Now)
- 事不宜迟 (Soon)
- 按部就班 (Later)
- 来日方长 (Someday)

### 2.3 四象限管理

基于重要性和紧急程度,待办事项自动分类到四象限:

| | 紧急 | 不紧急 |
|---------|------|--------|
| **重要** | 第一象限: 立即处理 | 第二象限: 计划执行 |
| **不重要** | 第三象限: 委托他人 | 第四象限: 尽量避免 |

**第一象限** (重要且紧急):
- 危机事件
- 紧急问题
- 截止日期迫近的任务

**第二象限** (重要但不紧急):
- 长期规划
- 能力提升
- 预防性措施

**第三象限** (不重要但紧急):
- 某些会议
- 某些电话
- 别人的紧急事项

**第四象限** (不重要且不紧急):
- 琐碎事务
- 娱乐活动
- 浪费时间的事

### 2.4 快速操作

#### 2.4.1 快速创建
- **抽屉模式**: 完整表单,所有字段
- **Popover模式**: 简化表单,快速创建
- **日历创建**: 从日历日期快速创建

#### 2.4.2 快速编辑
- **内联编辑**: 直接在列表中编辑
- **抽屉编辑**: 打开抽屉编辑完整信息
- **迷你编辑器**: 轻量级编辑器

#### 2.4.3 状态切换
- **一键完成**: 快速标记为已完成
- **一键放弃**: 快速标记为已放弃
- **恢复待办**: 将已放弃的待办恢复

#### 2.4.4 批量操作
- **批量修改状态**: 选中多个待办统一修改状态
- **批量删除**: 删除多个待办
- **批量调整日期**: 统一调整计划日期

### 2.5 搜索与筛选

#### 2.5.1 搜索
- **关键词搜索**: 名称、描述
- **标签搜索**: 按标签筛选(未来)
- **日期范围**: 按日期范围搜索

#### 2.5.2 筛选
- **状态筛选**: 多选
- **优先级筛选**: 重要性+紧急程度
- **关联任务**: 筛选特定任务的待办
- **关联目标**: 筛选特定目标的待办
- **时间范围**: 按计划时间筛选

### 2.6 数据统计

#### 2.6.1 统计指标
- **总待办数**: 所有待办总数
- **完成率**: 已完成 / 总数
- **高优先级**: 高优先级任务数
- **过期任务**: 已过期未完成的任务数
- **平均完成时间**: 从创建到完成的平均时间

#### 2.6.2 趋势分析
- **每日完成趋势**: 折线图
- **每周完成趋势**: 柱状图
- **优先级分布**: 饼图
- **完成率趋势**: 折线图

#### 2.6.3 优先级矩阵
- **四象限分布**: 可视化展示
- **各象限数量**: 每个象限的任务数
- **各象限完成率**: 完成情况对比

详见: [统计分析文档](./statistics.md)
