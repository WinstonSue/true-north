# 任务管理 - 功能说明

## 模块概述

任务管理模块是连接目标和待办的中间层,负责将长期目标分解为可执行的中期任务。

**核心价值**:
- 目标分解为具体任务
- 任务时间跟踪
- 支持任务层级关系

## 核心功能

### 📊 任务视图
- **当前任务** (task-week): 本周任务列表
- **任务日历** (task-calendar): 日历视图展示
- **全部任务** (task-all): 列表视图,支持筛选排序

### 🔗 二选一关联规则

> [!IMPORTANT]
> 任务二选一关联规则
> - 如果 isSubTask = true, 必须有 parentId
> - 如果 isSubTask = false, 必须有 goalId
> - 两者互斥,不能同时存在

### ⏱️ 时间跟踪
- 支持记录任务的实际工作时间
- 每条记录包含开始时间、结束时间、备注
- 自动累计总时间,与预估时间对比

### 🎯 关联信息
- 子任务列表展示
- 待办列表展示
- 快速创建关联项

## 约束规则

> [!IMPORTANT]
> 任务约束规则确保任务与目标/父任务的一致性

### 时间约束
- 子任务的时间范围必须在父任务范围内
- 关联目标的任务时间范围必须在目标范围内
- 动态提示允许的时间范围

### 重要程度约束
- 子任务的重要程度不能高于父任务
- 关联目标的任务重要程度不能高于目标
- 不符合约束的选项显示为禁用状态

## 用户界面

**布局**: 标签页切换(当前/日历/全部) + 任务列表/日历/表格

**交互**:
- 一键完成/放弃任务
- 批量操作支持
- 抽屉式详情编辑
