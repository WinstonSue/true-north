# 任务管理 - 产品需求文档 (PRD)

## 1. 功能需求

### 1.1 任务视图

#### 当前任务 (task-week)

- **页面类型**: 独立页面
- **功能**: 展示本周的任务列表
- **布局**: 列表形式,按状态分组
- **操作**: 快速创建、编辑、完成任务

#### 任务日历 (task-calendar)

- **页面类型**: 独立页面
- **功能**: 日历视图展示任务
- **布局**: 月度日历,日期单元格显示任务
- **操作**: 点击日期查看任务,拖拽调整时间(未来)

#### 全部任务 (task-all)

- **页面类型**: 独立页面
- **功能**: 所有任务的列表视图
- **布局**: 表格形式,支持筛选排序
- **操作**: 批量操作、高级筛选

#### 任务详情 (task-detail/:id)

- **页面类型**: 独立页面
- **功能**: 查看和编辑单个任务的详细信息
- **入口**: 
  - 从任务列表/日历点击任务
  - 从目标详情页的关联任务列表点击任务
- **布局**: 左右分栏结构(参考目标详情页)
  - 左侧: 任务树(父任务/子任务层级)
  - 右侧: 任务详细信息

### 1.2 任务属性

#### 基础属性

- **任务名称** (name): 必填
- **描述** (description): 可选
- **状态** (status):
  - 待办 (Todo)
  - 进行中 (InProgress)
  - 已完成 (Done)
  - 已放弃 (Abandoned)

#### 关联属性

> [!IMPORTANT]
> 任务二选一关联规则
> - 如果 isSubTask = true, 必须有 parentId
> - 如果 isSubTask = false, 必须有 goalId
> - 两者互斥,不能同时存在

- **是否子任务** (isSubTask): 布尔值
- **父任务** (parentId): 如果是子任务,必须关联父任务
- **关联目标** (goalId): 如果不是子任务,必须关联目标

#### 时间属性

- **计划时间范围** (planTimeRange): [startTime, endTime]
- **预估时间** (estimateTime): 预计需要的工作时间
- **实际跟踪时间** (trackTimeList): 时间跟踪记录数组

#### 评估属性

- **重要程度** (importance): 继承自父任务或目标的约束

### 1.3 约束规则

> [!IMPORTANT]
> 任务约束规则确保任务与目标/父任务的一致性

#### 时间约束

- 如果是子任务,时间范围必须在父任务范围内
- 如果关联目标,时间范围必须在目标范围内
- 动态提示允许的时间范围

#### 重要程度约束

- 子任务的重要程度不能高于父任务
- 关联目标的任务重要程度不能高于目标
- 不符合约束的选项显示为禁用状态

### 1.4 时间跟踪功能

#### 功能描述

支持记录任务的实际工作时间,帮助用户了解时间投入。

#### 时间记录

每条记录包含:

- **开始时间**: 开始工作的时间
- **结束时间**: 结束工作的时间
- **备注**: 可选,记录工作内容

#### 时间统计

- 自动累计总时间
- 与预估时间对比
- 时间分布分析

### 1.5 关联信息

#### 子任务列表

- 显示当前任务的所有子任务
- 支持快速创建子任务
- 显示子任务状态和进度
- 点击子任务跳转到该子任务的详情页

#### 待办列表

- 显示关联到该任务的所有待办事项
- 支持快速创建待办
- 显示待办完成情况

### 2.2 任务详情页布局结构

参考目标详情页的左右分栏结构:

```
┌─────────────────────────────────────────────┐
│  Task Detail                                 │
├──────────────┬──────────────────────────────┤
│              │                              │
│  左侧面板    │  右侧详情面板                │
│  (320px)     │                              │
│              │                              │
│  ┌────────┐  │  ┌────────────────────────┐  │
│  │筛选器  │  │  │  任务详情头部          │  │
│  └────────┘  │  └────────────────────────┘  │
│              │  ┌────────────────────────┐  │
│  ┌────────┐  │  │  任务表单              │  │
│  │任务树  │  │  │  - 基础信息            │  │
│  │        │  │  │  - 关联信息            │  │
│  │父任务  │  │  │  - 时间跟踪            │  │

└──────────────┴──────────────────────────────┘
```

**左侧面板**:

- **筛选器**: 按状态、时间范围筛选任务
- **任务树**: 
  - 显示父任务和子任务的层级关系
  - 如果是子任务,显示其所有同级子任务
  - 支持展开/收起子任务
  - 点击任务节点切换右侧详情
- **新建按钮**: 快速创建子任务

**右侧详情面板**:

- **任务详情头部**: 
  - 任务名称
  - 状态标签
  - 操作按钮(编辑/完成/放弃/删除)
- **任务表单**:
  - 基础信息(名称、描述、状态)
  - 关联信息(父任务/目标)
  - 时间信息(计划时间、预估时间)
  - 重要程度
  - 时间跟踪记录列表
- **关联信息**:
  - 子任务列表(点击跳转到子任务详情)
  - 待办列表(显示关联的待办)

### 2.3 任务表单

#### 创建模式

- 通过抽屉打开表单
- 支持快速创建
- 自动判断是否显示"是否子任务"开关

#### 编辑模式

- 在详情页直接编辑
- 修改后自动保存
- 支持取消修改

### 2.4 交互设计

#### 页面导航

- **Tab导航**: 在当前任务/日历/全部任务之间切换
- **路由跳转**: 点击任务卡片/列表项跳转到任务详情页
- **面包屑**: 任务详情页显示导航路径

#### 任务树交互

- **点击节点**: 在右侧显示详情
- **展开/收起**: 点击箭头图标展开/收起子任务
- **新建子任务**: 左侧面板底部"新建"按钮

#### 快速操作

- 一键完成任务
- 一键放弃任务
- 快速编辑

#### 批量操作

- 批量修改状态
- 批量删除
- 批量调整时间

#### 表单逻辑

- 创建模式下,如果有父任务id或目标id,则不显示"是否子任务"开关
- 根据 isSubTask 动态显示父任务选择器或目标选择器
- 约束规则自动验证和提示

#### 关联跳转

- **子任务**: 点击子任务列表中的任务,跳转到该子任务的详情页
- **待办**: 点击待办列表中的待办,打开待办详情抽屉(未来)
