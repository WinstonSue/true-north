# 目标管理 - 功能说明

## 模块概述

目标管理模块提供树形结构的目标管理系统,支持目标的创建、编辑、层级管理和进度跟踪。

**核心价值**:
- 通过树形层级组织长期目标
- 目标分解和进度追踪
- 父子约束确保目标体系一致性

## 核心功能

### 🌲 目标树形管理
- 树形展示,支持展开/收起子目标
- 懒加载机制,优化大数据量性能
- 支持无限层级的父子目标关系

### ✏️ 目标CRUD操作
- 创建目标(根目标/子目标)
- 编辑目标(只读/编辑模式切换)
- 删除目标(二次确认+级联影响提示)
- 状态管理(5种状态)

### 🔗 关联信息
- 子目标列表展示
- 关联任务列表展示
- 进度统计计算

### 🔍 搜索与筛选
- 按名称/描述搜索
- 多维度筛选(状态/类型/重要程度/难度/日期)
- 一键清除筛选

## 约束规则

> [!IMPORTANT]
> 约束规则确保目标体系的一致性

### 时间约束
- 子目标的时间范围必须在父目标时间范围内
- 系统自动限制日期选择器的可选范围

### 重要程度约束
- 子目标的重要程度不能高于父目标
- 不符合约束的选项显示为禁用状态

## 用户界面

**布局**: 左侧面板(筛选器+目标树) + 右侧详情面板(表单+关联信息)

**交互**:
- 点击树节点查看详情
- 双击进入编辑模式
- 右键菜单快速操作
